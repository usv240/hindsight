Safety

Operating boundaries

  • Dry-run by default. Nothing is written to the catalog without explicit approval{{ info('approval-gate') }}.
  • Every write is re-read. A write that cannot be read back is treated as a failure{{ info('reread') }}.
  • No authentication. This console can write to your catalog. It binds to loopback by default; put it behind an authenticating proxy before exposing it.
  • An LLM cannot promote a verdict. Only deterministic evidence reaches confirmed{{ info('verdict-lattice') }}.
