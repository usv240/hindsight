# DataHub Core development stack

`datahub.quickstart.yml` is the official quickstart Compose file generated by DataHub CLI 1.6.0.16 for Core v1.5.0.6 on 2026-07-27.

Two local-development changes are applied:

- MySQL's published host port uses `${DATAHUB_MAPPED_MYSQL_PORT:-3306}` instead of the generated literal `3306`. This makes the CLI's documented `--mysql-port` option effective and avoids stopping an unrelated local MySQL service.
- MySQL uses the isolated `hindsight_datahub_mysqldata_v2` volume. Existing DataHub volumes are left untouched.

Start it with:

```powershell
uv run datahub docker quickstart `
  --quickstart-compose-file docker/datahub.quickstart.yml `
  --mysql-port 3307 `
  --no-pull-images `
  --dump-logs-on-failure
```

The database remains reachable as `mysql:3306` inside the Compose network; only the host binding changes.
