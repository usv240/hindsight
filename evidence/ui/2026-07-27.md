# Evidence console implementation - 2026-07-27

The judge-facing evidence console is a server-rendered FastAPI/Jinja
application with no SPA or external frontend dependency.

## Verified surfaces

| Surface | Result |
|---|---|
| `hindsight serve` on `127.0.0.1:8100` | Pass |
| `/health` | `200`, `status=ok` |
| `/` rendered evidence page | `200`, 8,043 bytes |
| `/static/styles.css` | `200`, 10,457 bytes |
| `/api/audit` deterministic bundle | `release_decision=block` |
| Dry-run HTML publication form | No network mutation |

The console displays the release decision, directional column path, observed
and reconstructed metrics, high-correlation safe control, visible execution
trace, verified SQL remediation, and approval-gated publication form. All
numbers come from `run_demo_audit`; the HTML and CLI do not maintain separate
demo values.

The layout includes semantic landmarks, labels, visible focus states, a skip
link, responsive breakpoints, high-contrast status treatments, and reduced
motion handling.
